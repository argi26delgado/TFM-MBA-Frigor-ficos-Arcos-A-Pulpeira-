# TFM-MBA-Frigor-ficos-Arcos-A-Pulpeira-
Frigoríficos Arcos ("A Pulpeira") busca diversificar su negocio con Ceviche de pulpo Ready-To-Eat. Fusiona cocina gallega y latina con cocción al vacío, envases ecológicos y trazabilidad QR. Proyecta 2,7 M€ el Año 1 con inversión del 5% en marketing para crecer en retail y HORECA.
